**# Real-Time-Weather-Forecast-IoT**
Real-time IoT weather monitoring system using Arduino Uno, DHT11, BMP180, and ESP8266 with ThingSpeak cloud integration for live temperature, humidity, and atmospheric pressure visualization.

**#  Hardware Used**

- Arduino Uno
- ESP8266 Wi-Fi Module
- DHT11 Temperature & Humidity Sensor
- BMP180 Barometric Pressure Sensor
- Jumper Wires
- Breadboard
- USB Cable

** # Software Used**

- Arduino IDE
- ThingSpeak Cloud Platform

**# Parameters Measured**

- Temperature (°C)
- Humidity (%)
- Atmospheric Pressure (hPa)
